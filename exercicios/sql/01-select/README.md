# SELECT com filtro e ordenação

**Módulo 6 · SQL e PostgreSQL · tópico: Consultas básicas** · banco: [a loja](../README.md)

## O que fazer

Em `solucao.sql`, escreva **uma consulta** que liste os **livros que custam menos de R$ 80,00**, do mais caro para o mais barato.

Colunas, nesta ordem e com estes nomes: `nome`, `preco_centavos`.

## Dicas
- R$ 80,00 em centavos é `8000`.
- Duas condições no `WHERE` se juntam com `AND`.
- `ORDER BY coluna DESC` ordena do maior para o menor.

## Rodar

```bash
npm run exercicio sql/01
```
